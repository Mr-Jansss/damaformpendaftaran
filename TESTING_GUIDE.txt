========================================
TROUBLESHOOTING:
========================================

MASALAH: Login langsung masuk tanpa kredensial
SOLUSI: 
- Clear browser storage dulu
- Buka http://localhost:3000/clear-storage.html
- Atau manual clear di browser console

MASALAH: Section tidak muncul saat diklik menu
SOLUSI:
- Buka browser console (F12)
- Lihat error message
- Pastikan tidak ada error JavaScript
- Refresh halaman (Ctrl+F5)

MASALAH: Data tidak muncul / error "Chart is not defined"
SOLUSI:
- Pastikan Chart.js sudah loaded
- Cek di Network tab browser (F12)
- Pastikan file chart.js ter-download

MASALAH: API error / 401 Unauthorized
SOLUSI:
- Logout dan login ulang
- Clear storage dan login lagi
- Pastikan backend server masih running

MASALAH: Backend server mati
SOLUSI:
- Buka terminal/command prompt
- cd ke folder backend
- Jalankan: node server.js
- Atau double click file start-backend.bat
