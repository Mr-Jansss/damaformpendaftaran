## 🔧 Troubleshooting

### ❌ Masalah: Login langsung masuk tanpa input
**Solusi:** Clear storage dulu di http://localhost:3000/clear-storage.html

### ❌ Masalah: Section tidak muncul saat diklik
**Solusi:** Hard refresh browser (Ctrl+Shift+R atau Ctrl+F5)

### ❌ Masalah: Data tidak muncul
**Solusi:** 
1. Logout
2. Clear storage
3. Login ulang

### ❌ Masalah: Backend error
**Solusi:** 
1. Buka terminal
2. `cd backend`
3. `node server.js`
